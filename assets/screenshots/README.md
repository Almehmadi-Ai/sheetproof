# Screenshots

Images in this folder show the tool in real use inside Open WebUI, captured on the bundled
generic sample data ([`../../examples/sample_sales.csv`](../../examples/sample_sales.csv)).
Each image corresponds to a demo in the project [README](../../README.md).

To reproduce any shot: start a chat in Open WebUI, attach `examples/sample_sales.csv`, and
paste the matching prompt from [`docs/examples.md`](../../docs/examples.md).
